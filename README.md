# Aim:
To build a web app using Django that uses AI & Spotify API to paste a playlist link, get all the songs from that playlist, takes input of 3-5 keywords/phrases about how u want the playlist to be.

Eg: Romantic love songs
The app will get an idea of your taste and then recommend you other songs like:
I wanna be yours - Arctic Monkey (lowk gets oxytocin flowing in my body)
Never forget you - Zara Larson
etc..

## Goals:
- Become more fluent in python & django and build projects which I personally faced problems for.
- Maybe try to make the AI smarter with each recommendation. (Eg: It gives you 5 songs, you can choose to add them to your spotify playlist (Spotify API) or refresh the list. The AI will take note about what songs are added the most about what keywords and which people prefer those type of songs by getting an idea using their current playlist)

## MAIN GOAL:
- My main objective of this project is to complete it from start to finish WITHOUT USING ANY AI/LLMs/ AI Assistance. **[Only catch is that I can use AI to design the frontend cuz I have no interest for learning frontend development (HTML, CSS, JS) right now.]
